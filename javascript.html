    Diferença entre WHILE e DO WHILE

    Observe o comportamento visual de cada estrutura. 

                let contador = 10;
            while (contador < 5) {
                area.innerHTML += "
    WHILE executou
    ";
            contador++; 
            }

    WHILE

    O while verifica a condição ANTES. 

                let contador = 10;
            do {
                area.innerHTML += "
    DO WHILE executou
    ";
                contador++;
            }while (contador < 5);

    DO WHILE

    O do while executa primeiro e verifica depois.
